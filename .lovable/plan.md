# Curriculum enrichment — Intermediate ch.8-10 & Advanced ch.8-12

Content-only work. No pricing, exam, or certificate changes.

## Decision on chapters 1-7

I reviewed all three levels. Beginner 1-7 covers "what AI is / tool landscape / prompting basics".
Intermediate 1-7 is already genuinely different material (how LLMs actually work, context windows,
advanced prompt engineering, automation, chatbots, data analysis, content at scale, marketing) and
Advanced 1-7 is different again (system architecture, product building, APIs, RAG, agents, product
strategy, pricing). So there is **no duplicated beginner content to rewrite** — I will not rewrite 1-7.
What I will do instead: deepen the *thin* parts of the chapters I touch and make sure the new 8-12
chapters build directly on 1-7 rather than restating them.

## What gets rewritten (the 8 thin chapters)

**Intermediate — creative, strategic work with tools**
- Ch.8 (id 7) — Choosing the right tool for the right job: a decision framework, tool-vs-tool
  comparisons, cost/quality/speed trade-offs, when *not* to use AI.
- Ch.9 (id 8) — Designing multi-tool workflows: chaining tools into a repeatable pipeline,
  research → draft → design → publish, handoff points, quality gates.
- Ch.10 (id 9) — Creative direction and consistent output at scale: brand voice systems,
  style guides for AI, design systems, reviewing and editing AI output like a director.

**Advanced — coding, building, and earning**
- Ch.8 (id 7) — Building real programs with AI: project structure, spec-first development,
  reading and debugging generated code, version control.
- Ch.9 (id 8) — From script to product: databases, auth, payments, deployment, monitoring.
- Ch.10 (id 9) — Running it like a company: roadmap, metrics, support, ops, legal basics.
- Ch.11 (id 10) — Making income: freelance, productized service, agency, SaaS — with pricing
  models, first-client playbook, and realistic numbers.
- Ch.12 (id 11) — Scaling and staying ahead: hiring/delegation with AI, systems, exit paths,
  keeping the graduation project as the capstone.

## Style

Each chapter uses the same visual building blocks already in these files: intro box, "ما ستتعلمه"
list, multiple `<h3>` sections with real explanation and worked examples, info boxes with sample
prompts, comparison tables/bullet grids, tool cards with links and level/cost badges, a practical
checklist (intermediate) / exercise box (advanced), plus 5 quiz questions each — same shape as today,
just far more substantial (target roughly 3-5x current length per chapter).
